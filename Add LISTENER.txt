#1. Login to server using grid user.

#2. Add the listener with the desired port

srvctl add listener -l LISTENER_CDEMO -p 1522

#3. Check the status of the new listener. At this point listener will be in "enabled" and "not running" state

srvctl status listener -l LISTENER_CDEMO


#4. Start the new listener

srvctl start listener -l LISTENER_CDEMO

#5. Change the local_listener parameter in the CDB database.

alter system set local_listener='(ADDRESS=(PROTOCOL=TCP)(HOST=10.224.13.3)(PORT=1522))' scope=both sid='*';

#6. In case you need to remove the listener below are the steps:

 a. Set the local_listener to different port if required (as in step #5).
 b. remove the listener using below command:
   srvctl remove listener -l LISTENER_CDEMO
